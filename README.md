# Roadlords Music

Online music assets for Roadlords.

## Structure

- `menu/` – main menu music
- `human/` – Human faction in-game playlist
- `orc/` – future Orc faction in-game playlist
- `undead/` – future Undead faction in-game playlist
- additional factions can use their own folder

The game loads the active faction's folder dynamically, so adding a new track to an existing faction does not require a new game build.
